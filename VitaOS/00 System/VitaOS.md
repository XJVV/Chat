# VitaOS
VitaOS es un sistema personal de vida construido en Obsidian. Su propósito es capturar, organizar, ejecutar, medir, visualizar y mejorar lo que ocurre en mi vida.

## Principios
1. **El sistema debe ser simple.**
2. Todo lo útil debe poder observarse a través del tiempo.
3. Una sola fuente de verdad.
4. Capturar debe ser rápido.
5. La vida no debe adaptarse al sistema.
6. Las carpetas representan contexto físico.
7. Propiedades y enlaces representan contexto lógico.
8. No crear estructura para categorías que pueden ser relaciones.
9. No medir por medir: una métrica debe ayudar a decidir.
10. Si administrar una parte cuesta más de lo que aporta, se simplifica o elimina.

## Qué es un sistema
Un sistema es un conjunto de comportamientos que, a lo largo del tiempo, puede observarse y recibir retroalimentación para comprobar si se está llegando a un fin.

## Flujo
```text
Mundo → Captura → Inbox → Procesamiento → Contexto
→ Acción / Conocimiento / Referencia / Evidencia
→ Resultado → Registro → Métrica → Visualización
→ Retroalimentación → Ajuste
```
