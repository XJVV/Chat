# VitaOS — Bóveda final
## Plugins
- Dataview
- Tasks
- Charts View
- Templater
## Templater
Configura `99 Templates` como carpeta de plantillas.
## Regla
Los datos se escriben una sola vez en su nota de origen. Home consulta esos datos.
## Uso
1. Home como centro de operaciones.
2. Inbox para capturas.
3. Procesar Inbox.
4. Proyectos para resultados.
5. Estudios por contexto.
6. Records mediante Templater.
7. Reviews para feedback.
8. Charts View para gráficas que respondan preguntas reales.
